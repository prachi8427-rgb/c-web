Program 03 - Recursion Using Local Variable

Problem Statement

Write a program to print numbers from 1 to 5 using recursion and a local variable.

Source Code

#include <stdio.h>

void ptr(int n)
{
	int x = n;
	if(x <= 5)
	{
		printf("%d ", x);
		ptr(x + 1);	
	}
}
void main()
{
	ptr(1);
}

Output

1 2 3 4 5
