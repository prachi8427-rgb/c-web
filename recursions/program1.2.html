Program 02 - Recursion Using Global Variable

Problem Statement

Write a program to print numbers from 1 to 5 using recursion and a global variable.

Source Code

#include <stdio.h>

int n = 1;

void ptr()
{
	if(n <= 5)
	{
		printf("%d ", n);
		n++;
		ptr();	
	}
}
void main()
{
	ptr();
}

Output

C:\TURBOC3\BIN>TC
1 2 3 4 5
