Program 01 - Pointer and Array

Problem Statement

Write a program in which a pointer points to an array and insert value from user through pointer.

Source Code

#include <stdio.h>

void main()
{
	int a[5], i;
	int *p;

	p = a;

	for(i = 1; i <= 5; i++)
	{
		printf("Enter %d value: ", i);
		scanf("%d", p);
		p++;
	}

	p = a;

	printf("\nArray values: ");
	for(i = 1; i <= 5; i++)
	{
		printf("%d ", *p);
		p++;
	}
}
